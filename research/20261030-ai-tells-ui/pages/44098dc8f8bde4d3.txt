2025年、あるスタートアップのCEOが困惑していました。自社のAI生成ランディングページを見た投資家から「これ、(某有名AIツール)で作ったでしょう?」と指摘されたからです。実際、その通りでした。 同じ頃、GitHub上では興味深い現象が起きていました。数百のAI生成プロジェクトが、まるでクローンのように似通った見た目で溢れかえっていたのです。 これが AIスロップ (AI Slop) 
の正体です。 そしてこの現象は、Webサイトだけにとどまりません。いま、営業スライドにも同じことが起きています。AIに少し詳しい人が見れば、「これはGeminiで作ったな」「Claudeっぽいな」と、使ったツールまで当てられてしまう時代です。 もしあなたのサイトやスライドが「AIっぽい」と言われたことがあるなら、この記事はそこからの脱出マップになるでしょう。 
AIスロップとは何か——distributional convergenceの正体 AIスロップ とは、AI生成コンテンツが似通ってしまう現象を指す俗語です。その背景には distributional convergence (分布収束)という現象があります。 
LLMは訓練データの最頻パターンに収束する性質があります。デザインにおいても、「プロフェッショナルなWebサイト」という指示に対して、最も確率の高いパターンを出力してしまうのです。 その結果、世界中のAI生成サイトが驚くほど似通った見た目になってしまいます。 Reddit r/vibecoding での開発者の証言をご紹介します: 
「POCやアイデア探索でAIに頼ると、必ず2パターンに収束する。パターンA:Revolut風のクリーンなバンキングサイト(白背景、紫〜青のグラデーション)。パターンB:ダークなサイバーパンク風(黒背景、ネオングロー効果)。毎回同じで、もうウンザリ」 ここに AIデザインのパラドックス 
が潜んでいます。誰もが「anti-slopプロンプト」を使うようになれば、それ自体が次のスロップパターンを生み出してしまうのです。 実際に同じ要件「アナリティクスプラットフォームのLP」をSkillなし/ありで生成すると、違いは一目瞭然です。 では、Beforeの何が問題なのか。具体的に見ていきましょう。 AIが必ず出す3大パターン 1. 紫グラデーション症候群

com/anthropics/claude-code/blob/main/plugins/frontend-design/skills/frontend-design/SKILL.md その核心部分を解剖してみましょう。 # Core Rule: NEVER use generic AI-generated aesthetics - No purple gradients, no 
Inter/Roboto/Arial fonts - No generic "modern" or "professional" aesthetics - Every design must have a specific theme or concept # Design Thinking Process: 1. PURPOSE: What is this for? (e.g., "vinyl 
record store") 2. TONE: What feeling? (e.g., "warm nostalgia") 3. CONSTRAINTS: What limits? (e.g., "mobile-first, accessible") 4. DIFFERENTIATION: How is this unique? (e.g., "feels handcrafted") 
このSkillの優れた点は 強制的な差別化 にあります。毎回異なるテーマ・フォント・配色を選ぶことを開発者に強制し、AIの distributional convergence を意図的に回避するのです。 さらに興味深いのは、デザインシステムの逆説的アプローチです: # Anti-Pattern Detection: - If color palette contains ANY shade 
of purple → REJECT - If fonts include Inter/Roboto/Arial → REJECT - If animation is basic hover/translateY → REJECT これは「やってはいけないこと」を明文化することで、AIの創造性を制約つき最適化に変えているのです。 2026年、デザイナーはAIスロップにどう応答しているか 
デザイン理論家 Ioana Teleanu の2026年の論文「Aesthetics in the AI Era」によると、AIスロップへの文化的反発として、3つの新しいデザイン潮流が登場しています。 1. Technical Mono(テクニカル・モノ) 特徴 : 単色(主にグレースケール)、等幅フォントオンリー、ASCII アートの多用 /* Technical Mono スタイル例 */

Aesthetic(監視の美学) 特徴 : セキュリティカメラのUI、CRT モニターグリッチ、緑色ターミナル風 /* Surveillance Aesthetic 例 */ .crt-screen { background : #001100 ; color : #00ff00 ; font-family : 'Share Tech Mono' , monospace ;

によると、これらは「人間らしさを取り戻そうとする文化のシグナル」なのです。AIが完璧なグリッドや整然とした配置を好むのに対し、人間は意図的な破綻や不完全さに美を見出すようになったのです。 まとめ——AIに「何を」伝えるべきか AIスロップから脱出する鍵は、AIに 「何を作るか」 ではなく 「何のために、誰のために、どんな体験を」 作るかを伝えることです。 ❌ ダメなプロンプト例
