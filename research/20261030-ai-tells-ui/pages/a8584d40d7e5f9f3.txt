0、納品50件超のLP制作者です。最近「AIでLPを作ってみたけど、なんか胡散臭い」「公開して2週間、アクセスはあるのに問い合わせ0件」という相談が続きます。AIの初稿は速いのに、なぜか人が動かない。その違和感の正体を、私が現場で使っている5つの計器で可視化し、すぐ直せる順に処方します。 共感:その“なんか”はデザインでも文章でも起きている 
AI初稿でよくある違和感は、見た目と文脈の両方に潜みます。 - 紫〜青の強いグラデーションが全面に広がる - 3列均等カードが上から下まで同じリズムで続く - 「あなたの課題を解決」「最適なソリューション」など意味の薄い抽象コピー - ストック写真の握手・会議風景・笑顔のビジネスパーソン - どのセクションも同じCTA「今すぐ相談する」 
結果として、3秒で「どんな人の、どんな状況に、どれくらい役立つのか」が伝わらず、離脱が増えます。私は2023年以降、AI初稿を土台に直したLPだけで51件納品しましたが、直すべきは“全否定”ではなく“温度・骨格・言い回し”の微調整です。 診断:直すときに見るべき5つの計器 1. 配色の“温度”を合わせる 
AIは安全側で彩度の高いコーポレート寄り配色を返しがちです。まず、ビジネスの体温に合わせます。 - 手仕事・食品・教室系:暖色寄りの低彩度。例)ベース #F7F4EF 、文字 #2A2A2A 、アクセント #C1693C 。60/30/10の比率で運用。 - B2B製造・会計・法務:寒色寄りの低彩度。例)ベース #F3F6F8 、文字 #1E242A 、アクセント #2F6CAB 。 - 
重要:テキストと背景のコントラスト比は4.5:1以上(WCAG AA)。Chrome拡張「Contrast Ratio」やFigmaのアクセシビリティで即確認。 AIの紫グラデは、具体を語れないときの“雰囲気作り”になりがち。まず単色ベース+1アクセントに引き算し、必要な場所だけ強調します。 2. フォントの“相性”を決め打ちする 日英混排で崩れるのはAI初稿の典型。日本語はNoto Sans 
JP、BIZ UDPゴシック、本文16–18px、見出し28–32px。装飾に使うなら見出しのみShippori Mincho。英字はInterかSource Sans 3に固定し、英字のみ-0.02em、日本語は字間0〜0.02em、行間1.6–1.8で統一。 例えば: ``` body { font-family: \'Noto Sans JP\', sans-serif; 
font-size: 16px; line-height: 1.75; letter-spacing: 0.02em; } h1,h2 { font-family: \'Shippori Mincho\', serif; font-weight: 700; line-height: 1.4; } .btn { font-family: \'Inter\', \'Noto Sans JP\', 
sans-serif; font-weight: 600; } ``` AIが勝手に混ぜた游ゴシック+任意の英字体は可読性が落ちます。見出しと本文の役割分担を“2書体まで”に固定すると“AI臭”が抜けます。 3. コピーの“粒度”を1段だけ具体に 抽象コピーは一読で忘れられます。私は「いつ・誰が・何を・どれくらい」を最低1つは入れるルールにしています。 - 抽象:手間なく集客を実現 - 
具体:毎週水曜の体験会に3名の予約を集めるテンプレート付き - 抽象:最適な制作体制 - 具体:写真2枚とヒアリング15分で初稿を48時間以内にお渡し ファーストビューの主語は“小さく狭く”。20〜26文字で具体を伝え、サブで条件を足します。例)見出し「自宅サロンの体験予約を週3件に」サブ「LINE返信テンプレと導線図をセットで」。 4. 装飾は“等速を壊す”ために使う 
3列均等カードが続くと、人は途中で読むのをやめます。私は「2-1リズム」か「1-2リズム」をよく使います。 - 上段は2カラム(左テキスト、右写真)、下段は1カラムで事例の抜粋 - 8pxグリッドで余白を設計(セクション間は40–64px、カード内は24–32px) - 影・グラデ・ガラス効果は最大1種まで。境界は1pxの#E6E6E6で十分 装飾は“読みやすさのための交通整理”に限定します。 
5. CTAは“文脈に接続”させる AIは全セクションに同じ「今すぐ相談」を置きがち。人は段階が合わない誘いに反応しません。 - 事例直後:この事例の設計図PDFを見る(全4ページ・598KB) - 価格表直後:見積もりの前にできる無料計測(2分) - ファーストビュー:写真2枚で無料診断を受ける(所要2分・24時間以内に返信) 
ボタン下の補足1行が効きます。「個人情報はメールのみ」「キャンセル自由」「土日も返信」など、摩擦を言語化してください。 処方:現場で実際にやった置き換え 事例1:大阪・堀江のパーソナルジム AI初稿は紫グラデ+3列メニュー+今すぐ相談。配色を#EDEAE3ベースに、文字#1E1E1E、アクセント#D96C2Fへ変更。見出し「月8回・50分。堀江で姿勢から整える」に差し替え、トップCTAを「体験50
分の空きを確認(所要30秒)」に。オーナーの姿勢計測写真を差し替え。公開翌月の予約フォーム到達率が0.6%→1.9%。 事例2:ハンドメイドアクセサリー作家(minne出店) AIの抽象コピーを、制作工程の実写3枚と共に「金具は14kgfのみ」「最短3日で発送」に置換。CTAは「金属アレルギー表をダウンロード(PDF1枚)」を商品下に設置。問い合わせ経由のカスタムオーダーが月1→月6に。 
事例3:大田区の試作板金工場 ストック写真の握手を廃止。機械名(AMADA RG-80)と対応板厚を書き添え、「図面PDFを送る(秘密保持契約あり)」をCTAに。担当直通の返信時間「平日9–18時、平均4時間」を明記。見積依頼が月2→月9に。 30分でできるセルフチェック手順 5分:配色の温度を決める。メイン1色、アクセント1色、比率60/30/10に。コントラスト4.5:1以上を確認。 2. 
7分:フォントを2書体までに統一。見出し28–32px、本文16–18px、行間1.6–1.8。 3. 8分:見出しを20–26文字に短縮し、数字と固有名詞を1つ入れる。 4. 5分:3列均等を崩し、2-1リズムに組み替える。余白は8pxグリッドで。 5. 5分:各セクション末に文脈CTAを1つずつ。ボタン下に摩擦を解く1行を添える。 Chrome 
DevToolsの“Lighthouse”でコントラストとタップ領域、FigmaのType Scaleで見出し階層を確認すると、手戻りが激減します。 自然な誘導:迷ったら“人の体温”で最終整形 AIの骨格は強いが、体温の調整は最後まで人の役割です。写真の選び方、言い換えの粒度、余白の癖は、事業主の空気に合わせて初めて整います。この記事の5つの計器で触ってみて、もし判断に迷ったら、第三者の目で20分
